## 內容品質邊界

- 法律與金額只採金管會、全國法規資料庫及司法院等官方來源。
- 不新增 FAQPage 或 HowTo schema；指南使用 Article、CollectionPage 與 BreadcrumbList。
- 每頁顯示整理者、最後檢視日期、官方來源及免責聲明。
- 不以單一判決、原告請求額或總和解金包裝成固定行情。
- 不用最低工資、傷名或住院日數替資料不足的個案硬填金額。
