- 事故日 ≥ 2026-07-01：新法（拆 subItems / 三分類查表）

## 🎓 怎麼用這份參考資料

1. **業務員估算時**：用同法院 / 同失能等級的 precedent 看 P10 ~ P90 範圍當作精神慰撫金參考
2. **遇到疑難案號**：搜 `keyHolding` 找類似事實的裁判要旨
3. **驗算 Hoffmann 係數**：上面 Hoffmann 計算範本可當 SOP 對照
4. **法規版本判定**：用事故日 ≥ / < 2026-07-01 切新舊法
5. **缺資料時**：參考補件清單，不硬算
