## 車損結果與修改流程優化（2026-10-23）

- 未受傷案件以車損、其他財損及對方負擔為摘要，預設開啟民事明細，略過失能、實務案例、強制險與地區分頁。
- 摘要可直接跳至補件／風險；新增「修改本次資料」，使用正在檢視的 ClaimInput 載入表單。載入與草稿還原共用初始化流程，修改後仍需重新核對。
- 第三人責任險說明修正為乘「對方」肇責。比例比較採主估算的完整民事損害中值，包含車輛損失，並統一總額四捨五入。
- 歷史實務案例缺少失能、重點摘要或收錄日期時不再造成結果頁崩潰。
- 36 項相關單元測試、4 項 Chrome 流程及 production build 通過。瀏覽器驗證含車損與拖吊合計 10,500 元、對方肇責 70% 為 7,350 元、補件跳轉、分頁完整載入，以及修改後保留日期、比例、維修費與未受傷狀態。
- 本輪修改檔案 lint 通過；仍為本機候選版。

## 表單精簡與資料不足處理（2026-10-23）

- 合併事故與肇責畫面：受傷四步、未受傷兩步；沿用資料區段編號，摘要修改入口回到合併畫面。
- 收入與請假資料按需展開，已填資料預設展開。醫院與急診日期移至選填；文字初篩與失能狀態集中到進階區。
- 無住院資料或費用時收合病房欄位，可手動補填；看護費依看護狀態或既有金額顯示。
- 看護日數僅在傷勢畫面填寫，送入醫療與收據區段時同步。舊草稿只有收據日數時自動帶入；兩者均有值時以傷勢日數為準。
- 填維修費即顯示事故前車價。未知車價時車損回傳 null，補件清單、明細及金額摘要均明示待估／未列入小計，避免誤認零元。
- 修正手機結果頁導覽列及長聯絡按鈕換行。390px 視窗驗證無頁面橫向溢出。
- 全部 99 個測試檔案、1,045 項測試通過；受傷、未受傷、分頁與手機共 5 項瀏覽器案例經修正重跑通過，包含 production build。修改檔案 lint 與型別檢查通過；尚未發布。
